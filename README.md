# ニンゲン家具 (Ningen Kagu)

部屋の家具に擬態して、巡回する鬼から **60秒間** 見つからずに生き残る、ブラウザだけで動く3Dステルスゲームです。

外部モデル・外部APIを使わず、Three.js のプリミティブ形状だけで作られています。
ビルド不要で、静的HTTPサーバーや GitHub Pages からそのまま公開できます。

## 遊び方

| 操作 | PC | スマホ |
|---|---|---|
| 移動 | `W` `A` `S` `D` / 矢印キー | 画面左の仮想スティック |
| 視点 | 画面をドラッグ | 画面をドラッグ |
| 擬態 | `E` | 右下の「擬態」ボタン |
| ポーズ切替 | `Q` / `Space` | 右下の「ポーズ」ボタン |

1. 家具や壁のそばで **擬態** を押すと、その物の色と材質をコピーします。
2. **ポーズ** で 直立 / Tポーズ / Yポーズ / しゃがみ を切り替えます。
   物によって「似合うポーズ」があり、合っていると HUD が **ポーズ◎** になります。
3. 60秒逃げ切れば勝ち。鬼の警戒度が振り切れたら負け。

## 擬態成功度の仕組み

HUD の「擬態 ○○%」は次の4つで決まります。

| 要素 | 内容 |
|---|---|
| 色 | **鬼から見てプレイヤーの背後にある物** の色と、自分の色がどれだけ近いか |
| 静止 | 完全に止まっているほど高い（動くと即座に下がる） |
| ポーズ | 擬態した物に合ったポーズかどうか |
| 距離 | 擬態した物の近くにいるかどうか |

擬態成功度が高いほど鬼に気づかれにくくなりますが、**100%にはならない**ので絶対安全にはなりません。

## スコア（見落としポイント）

鬼の視界に入っているのに気づかれていない間、スコアが増え続けます。

- 鬼に近いほど倍率アップ
- 鬼の視線の中心にいるほど倍率アップ
- 警戒度が高いほど倍率アップ
- 目の前でじっと見つめられて耐え切ると **見逃しボーナス**

つまり、安全な隅に隠れるより **鬼の目の前で家具になりきる** 方が高得点です。

## 構成

```
index.html          エントリポイント
css/style.css       UI / HUD / スマホ操作
js/main.js          レンダラ・ライト・ゲームループ・UI配線
js/game.js          ゲーム進行、擬態成功度、発見判定、スコア
js/stage.js         部屋と家具の生成、擬態対象、当たり判定
js/player.js        人型キャラクターとポーズ
js/oni.js           鬼NPC（巡回・視界・遮蔽判定）
js/input.js         キーボード / マウス / タッチ入力
js/hud.js           画面表示
js/effects.js       擬態エフェクト、対象マーカー
js/audio.js         WebAudio で合成する効果音（音素材ファイル不要）
vendor/three/       Three.js r180 (MIT)
```

## 動かす

アプリサーバーやビルド処理は不要ですが、ES モジュールを使うため `file://` ではなく HTTP で開いてください。

```sh
python3 -m http.server 8000
# http://localhost:8000/
```

## GitHub Pages で公開

リポジトリの Settings → Pages で Branch にこのブランチ、フォルダに `/ (root)` を指定するだけです。
（Jekyll の処理を避けるため `.nojekyll` を置いてあります）
